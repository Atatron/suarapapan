# Offline speech regression sample

`speech-8khz.raw` is the unmodified 8 kHz, mono, signed little-endian 16-bit
`test-audio.raw` fixture from `wiseman/py-webrtcvad` commit
`e283ca41df3a84b0e87fb1f5cb9b21580a286b09`.

Source: <https://github.com/wiseman/py-webrtcvad/blob/e283ca41df3a84b0e87fb1f5cb9b21580a286b09/test-audio.raw>

SHA-256: `3dbb730b90e0266d78d4fe03f00aba37a83780a6a5240d9084b5c01266194c1e`.
The source repository's MIT license is retained in `LICENSE`.

This is a positive speech fixture for the local classifier. It does not establish
Indonesian transcription accuracy, microphone quality, or classroom performance.
Negative fixtures are deterministic synthetic noise generated by `audio.js`.
